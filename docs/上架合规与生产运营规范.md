# PetFriendly 上架合规与生产运营规范

> 基线版本：2026-08-11。本文档是产品与工程规范，不替代执业律师、税务或支付机构的专业意见。

## 1. 发布渠道

- 当前私有文件服务 IPA + iLoader 属于私有设备分发链路，予以保留。
- 若提交 Apple App Store，必须构建 App Store 专用配置：更新按钮指向 App Store，不得引导下载 IPA。私有包和 App Store 包使用不同的 Build Configuration/功能开关。
- 发布前必须完成：功能完整性、IPv6-only、权限拒绝路径、账号删除、UGC 举报/屏蔽、隐私清单、审核测试账号与后端稳定性验证。

## 2. UGC 内容治理

UGC 范围包括场所投稿、照片、评价、用户资料、聊天、服务进度图片与反馈。

1. 发布前：参数校验、禁止词/规则过滤、图片安全检测；高风险内容不直接公开。
2. 发布后：内容页可举报，用户页可举报并屏蔽，屏蔽后不再展示对方评价。
3. 后台：举报状态为待处理、处理中、已解决、已驳回；处理人、结论和时间留痕。
4. SLA：人身威胁、未成年人、动物虐待、诈骗、个人信息泄露立即升级；其他举抨24小时内开始处理。
5. 处置：驳回、隐藏、删除、限制发布、禁言、停用账号；保留申诉通道和必要证据。

## 3. 隐私与协议

- 注册页须由用户主动勾选，不得默认同意。记录用户ID、文档类型、版本、时间、IP 和 User-Agent。
- 隐私文档变更使用 `YYYY-MM-DD` 版本；收集目的、范围、第三方或保留期发生实质变更时重新征得同意。
- App Store Connect 的 Privacy Nutrition Label 必须与 `PrivacyInfo.xcprivacy`、实际 API 与第三方 SDK 一致。
- 数据导出和账号注销从 App 内可直接发起。注销时删除或匿名化用户资料和 UGC；法定交易、税务、安全、争议记录隔离保留。

## 4. 网络与位置

- 生产 API、对象存储、隐私政策、分发与内网穿透入口全部使用 HTTPS，证书可验证且支持 TLS 1.2+。不在 Release `Info.plist` 保留 ATS HTTP 例外。
- 内网 HTTP 调试仅限 Debug 构建、受控 LAN/VPN，不进入 IPA Release 配置。
- 客户端只申请 When In Use 位置，不声明后台位置。拒绝时提供手动选择地址或地图浏览。
- 生产 API Base URL 必须由 CI 注入 Secrets，客户端 Release 不得允许普通用户改为 HTTP 或未信任主机。

## 5. 积分、钱包与 AI

- 积分：仅能从签到、审核通过的贡献和活动获得，仅用于积分商城；不可购买、转账、提现或支付 AI。
- 钱包：仅用于订单支付、充值、提现和订单退款。不得在无支付机构成功回调时入账；提现为申请制，必须实名、风控、审核和对账。
- 开发环境如需模拟充值，显式设置 `pet-friendly.wallet.allow-simulated-recharge=true`；生产必须保持 `false`。
- AI：不扣减积分。紧急对话持续显示“AI生成/非兽医诊断”，对高风险症状优先展示就医建议。

## 6. 中国大陆 AI 标识与备案

- AI 文本、图片、音频、视频在展示与导出时添加用户可感知的显式标识。
- 上线前接入符合现行国家标准的隐式标识能力：导出文件元数据记录 AI 属性、服务提供者/编码、内容编号等信息；不得提供默认去标识功能。当前版本已实现图片显式水印，隐式标识仍是生产发布门禁项。
- 生成、下载、复制、发布时保留必要日志。对可公开发布的 AI 内容审核输入和输出。
- 上线前核对 APP 备案、域名 ICP、算法备案/登记、已备案模型名称与备案号公示。

## 7. CI/CD 门禁

CI/CD 流水线发布前至少执行 Maven compile/test、管理端类型检查与构建、iOS Release archive、Privacy Manifest 校验、密钥扫描、HTTP/ATS 扫描。任一步失败不上传分发包，不更新生产环境部署。
